# Welcome to the GATAS Connect community

Use **Q&A** for questions and help, **Ideas** for improvements, and
**Announcements** for maintainer updates. Mark a helpful Q&A answer as the
solution when your question is resolved.

For reproducible app problems, please use the structured **Bug report** issue
form. Include your app version, build number and reproduction steps. Remove
personal information from logs and screenshots.

You are also welcome on [Discord](https://discord.com/invite/J6mXTcWndS).
You can request an invitation to the iPhone/iPad TestFlight beta there.

The application source code and internal iOS build records are maintained
privately. This repository hosts new Android downloads, licenses, screenshots
and community support. Older builds are not imported.
